## 🚀 One-Minute Overview

**What is it?**
Settings page where admins can view, edit, and manage all AI system instructions.

**Why?**
No more hidden context. Everything is transparent and configurable.

**Where?**
Settings (⚙️ icon) → AI Context tab (⚡ icon)

**How?**
Edit 5 sections (System, Rules, Business, Isolation, Vocabulary) and click Save.

**When do changes take effect?**
Immediately for new conversations.

**Can it be reverted?**
Yes, one-click reset to defaults.
