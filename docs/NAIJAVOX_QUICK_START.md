# NaijaVox-2.0 Quick Integration Guide\n\n## ⚡ 5-Minute Setup\n\nThis guide gets you from zero to NaijaVox in minutes.\n\n### Prerequisites\n- Python 3.9+\n- ~3GB disk space (for model)\n- 4GB+ RAM (8GB recommended)\n- GPU optional (NVIDIA CUDA for faster inference)\n\n### Step 1: Install (2 minutes)\n\n```bash\ncd backend\n\n# Ensure virtual environment is active\nsource venv/bin/activate  # Linux/Mac\n# or\nvenv\\Scripts\\activate  # Windows\n\n# Install/update requirements\npip install -r requirements.txt\n```\n\n### Step 2: Configure (1 minute - Optional)\n\nEdit `backend/.env`:\n\n```bash\n# Auto-detect (recommended)\nNAIJAVOX_DEVICE=auto\n\n# Or force specific device\n# NAIJAVOX_DEVICE=cuda      # For NVIDIA GPU\n# NAIJAVOX_DEVICE=cpu       # For CPU only\n\n# Optimization\nNAIJAVOX_TORCH_DTYPE=float16   # GPU: fast + low memory\n# NAIJAVOX_TORCH_DTYPE=float32   # CPU: more stable\n```\n\n### Step 3: Run (1 minute)\n\n```bash\n# Start the app\npython run.py\n\n# On first run:\n# - NaijaVox model downloads (~2.5GB) - 5-10 minutes\n# - Model is cached for future runs\n```\n\n### Step 4: Test (1 minute)\n\n```\n1. Open http://localhost:5001\n2. Login: admin@brainr.com / @@AdminBrainer22\n3. Go to Settings → Audio\n4. Select \"NaijaVox-2.0 (Nigerian Languages)\"\n5. Choose language (Yoruba/Hausa/Igbo/Pidgin)\n6. Click \"Test Audio\"\n7. Speak! 🎤\n```\n\nExpected output:\n```\n✓ Transcribed with NaijaVox-2.0: XXX chars\n```\n\n---\n\n## 🎯 Common Scenarios\n\n### Scenario 1: Voice Query in Yoruba\n\n```\nUser (Yoruba): \"Kí lo ni awọ̀n emails mi?\"\n              (What are my emails?)\n                    ↓\n         [NaijaVox transcribes]\n                    ↓\n         [App connects to email]\n                    ↓\n      [Returns emails to user]\n```\n\n**Setup**:\n1.
