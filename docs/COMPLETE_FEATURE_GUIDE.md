# Brainr App: Complete Feature Overview with NaijaVox Integration\n\n## Executive Summary\n\nThe brainr app is a powerful AI assistant with enterprise-grade security, multi-language support, and advanced audio processing. It can perform complex queries, manage emails, and respond intelligently—all while respecting role-based access controls and security policies set by administrators.\n\n---\n\n## 🎤 Audio Features with NaijaVox-2.0\n\n### Speech-to-Text (STT) Pipeline\n\n```\nUser speaks in Nigerian language (Yoruba/Hausa/Igbo/Pidgin/English)\n                        ↓\n                  [Record Audio]\n                        ↓\n            [NaijaVox-2.0 ASR Model]\n                        ↓\n        [Transcribed to Text in Original Language]\n                        ↓\n            [Optional: Translate to English]\n                        ↓\n        [Send to LLM for Processing]\n```\n\n### Supported Languages\n- 🇳🇬 **Yoruba** (with full diacritics: ẹ, ọ, ṣ, à, á)\n- 🇳🇬 **Hausa** (with special characters: ƙ, ƴ, ɗ)\n- 🇳🇬 **Igbo** (with diacritics)\n- 🇳🇬 **Nigerian Pidgin** (Creole English)\n- 🇳🇬 **Nigerian-accented English**\n\n### Features\n- ✅ **22.58% Average WER** (Word Error Rate)\n- ✅ **Noise Robust** (trained on market noise, phone compression, outdoor audio)\n- ✅ **Code-Switching Aware** (understands language mixing)\n- ✅ **Real-time Transcription**\n- ✅ **Multi-Speaker Diarization** (identifies who said what)\n- ✅ **Offline Capable** (after first download)\n- ✅ **Free & Open Source** (Apache 2.0 license)\n\n### Text-to-Speech (TTS) Options\n- **Google Cloud TTS**: Premium quality, supports African languages\n- **ElevenLabs**: High-quality voices, diarization support\n- **Local Models**: Free alternatives (coming soon)\n\n---\n\n## 📧 Email Management Features\n\n### What the App Can Do\n\n#### 1. **Read Emails**\n```\nUser Command (Voice or Text): \"Check my emails\"\n                    ↓\n            [App connects to email]\n                    ↓\n        [Retrieves unread messages]\n                    ↓\n    [Summarizes & reads to user]\n```\n\n**Supported Email Services**:\n- Gmail (via IMAP)\n- Microsoft Outlook\n- Yahoo Mail\n- Any IMAP-compatible email provider\n\n**Email Reading Features**:\n- List all unread emails\n- Show emails from specific sender\n- Filter by date range\n- Search by keyword\n- Extract attachments (coming soon)\n\n#### 2. **Respond to Emails**\n```\nUser Command: \"Reply to [sender] saying [message]\"\n                    ↓\n        [Compose reply email]\n                    ↓\n        [Apply security checks]\n                    ↓\n            [Send email]\n```\n\n**Response Features**:\n- Quick replies\n- Scheduled sending\n- Template responses\n- Auto-complete suggestions\n- Signature support\n\n#### 3. **Email Scheduling**\n```\nUser: \"Schedule email for tomorrow at 9 AM\"\n            ↓\n    [App schedules task]\n            ↓\n    [Sends at specified time]\n```\n\n---\n\n## 🔐 Security & Permissions\n\n### Role-Based Access Control (RBAC)\n\nThe app enforces role-based permissions on **ALL features**:\n\n```\nUser Role: Editor\n├─ Can: Chat with LLM\n├─ Can: Upload documents\n├─ Can: Query database (if permitted)\n├─ Can: Train custom models\n└─ Cannot: Manage users (Admin only)\n\nUser Role: Viewer\n├─ Can: View conversations\n├─ Can: Export reports\n└─ Cannot: Modify data\n\nUser Role: Admin\n├─ Can: Everything\n├─ Manage: Users, Roles, Permissions\n├─ Access: All security settings\n└─ Control: Feature availability per role\n```\n\n### Security Policies (Admin Configurable)\n\nAdmins can configure:\n\n1. **Email Access**\n   - ✅ Allow all users to read emails\n   - ✅ Allow specific roles only\n   - ✅ Restrict to specific senders/domains\n   - ✅ Audit all email activity\n\n2. **Query Restrictions**\n   - ✅ Limit database access by table/column\n   - ✅ SQL injection prevention (SQL Guard)\n   - ✅ Row-level security (user-specific data filtering)\n   - ✅ Audit logging for all queries\n\n3. **Audio Features**\n   - ✅ Enable/disable STT per role\n   - ✅ Choose STT model (NaijaVox, Whisper, etc.)\n   - ✅ Enable/disable TTS\n   - ✅ Language restrictions\n\n4. **External Auth**\n   - ✅ OAuth2/OIDC integration\n   - ✅ LDAP/Active Directory\n   - ✅ Custom token validation\n   - ✅ Multi-factor authentication (MFA)\n\n---\n\n## 🤖 Query Processing & LLM Integration\n\n### How Queries Work\n\n```\nUser Input (Voice/Text)\n        ↓\n[NaijaVox: Convert speech to text]\n        ↓\n[Parse intent & extract parameters]\n        ↓\n[Check permissions for requested action]\n        ↓\n[Route to appropriate module]\n        ├─ Database Query → [SQL Guard] → [Execute] → [Filter results]\n        ├─ Email Reading → [IMAP] → [Fetch] → [Filter by permissions]\n        ├─ Email Writing → [Compose] → [Approval] → [Send]\n        └─ General Chat → [LLM] → [Generate response]\n        ↓\n[Format response]\n        ↓\n[TTS: Convert to audio in selected language]\n        ↓\nUser receives response (audio + text)\n```\n\n### Query Types\n\n#### 1. **Database Queries (Text-to-SQL)**\n```\nUser: \"How many active customers do we have in Lagos?\"\n            ↓\n    [LLM converts to SQL]\n            ↓\n    SELECT COUNT(*) FROM customers WHERE city='Lagos' AND status='active'\n            ↓\n    [SQL Guard checks permissions]\n            ↓\n    [User can access customers table? YES]\n            ↓\n    [Execute & return results]\n```\n\n#### 2. **Email Queries**\n```\nUser: \"Did I get any emails from the CEO today?\"\n            ↓\n    [Connect to email]\n            ↓\n    [Filter: from=CEO, date=today]\n            ↓\n    [Check permissions]\n            ↓\n    [Return matching emails]\n```\n\n#### 3. **Multi-Turn Conversations**\n```\nUser (Turn 1): \"What was my revenue last month?\"\n        ↓\n    [LLM queries database]\n        ↓\nApp: \"Your revenue was $50,000\"\n\nUser (Turn 2): \"How does that compare to the month before?\"\n        ↓\n    [LLM remembers context]\n        ↓\n    [Query: previous month]\n        ↓\nApp: \"Previous month was $45,000, an increase of 11%\"\n\nUser (Turn 3): \"Send an email to finance with these numbers\"\n        ↓\n    [LLM composes email]\n        ↓\n    [Check email permissions]\n        ↓\n    [Send email]\n```\n\n#### 4. **File Processing & Analysis**\n```\nUser: \"Analyze the sales data in this CSV\"\n        ↓\n    [Upload CSV]\n        ↓\n    [Parse file]\n        ↓\n    [Feed to LLM with file content]\n        ↓\n    [Generate insights]\n        ↓\n    [Present findings]\n```\n\n---\n\n## 🌍 Multi-Language Support\n\n### Current Implementation\n\n**Input Languages**:\n- English\n- Igbo\n- Hausa\n- Yoruba\n- Nigerian Pidgin\n- (50+ via Whisper fallback)\n\n**Processing**:\n- Speech → Text (NaijaVox-2.0)\n- Text → LLM Processing (in English or original language)\n- LLM Output → Speech (TTS in selected language)\n\n**Diarization in Multiple Languages**:\n```\nMulti-speaker Yoruba audio\n        ↓\n[NaijaVox transcribes each speaker]\n        ↓\n[LLM identifies speaker context]\n        ↓\n\"Speaker 1: 'Bawo ni e n lo?'\n Speaker 2: 'O kere. Tun mo soko to ni'\"\n```\n\n---\n\n## 🔧 Admin Configuration Panel\n\nAdmins can configure everything from the Security & Permissions pages:\n\n### Pages Available\n\n1. **Users & Roles**\n   - Create custom roles\n   -
