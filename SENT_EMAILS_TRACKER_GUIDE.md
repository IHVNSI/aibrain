# Comprehensive Sent Emails Tracker

## Overview

The Sent Emails view now provides a complete tracking system for all outgoing emails from the Brainr app. You can see:
- ✅ **All Sent Emails** - Every email successfully sent
- 🤖 **AI Auto-Replies** - Emails automatically generated by AI
- ↩️ **Manual Replies** - Emails you personally replied to
- 📤 **Outbox** - Pending emails not yet sent
- ❌ **Failed** - Emails that failed to send

---

## How to Access

1. Go to **Email tab** → **Sent** (in left sidebar)
2. You'll see the Sent Emails view with filter buttons at the top

---

## Filter Options

### 1. All Emails (Default)
Shows every email sent from the app, sorted by most recent first.

**Statistics shown:**
- Total count of all sent emails

### 2. 🤖 AI Auto-Replies
Shows only emails that were **automatically generated by AI**.

**Includes:**
- Auto-replies triggered by received emails
- System-generated responses
- AI-based customer service responses

**Badge:** Purple "🤖 AI Generated" badge

**How it works:**
- When an email arrives and auto-reply is enabled, AI generates a response
- Response is automatically sent to the sender
- Tracked with `ai_generated: true` flag

### 3. ↩️ Manual Replies
Shows emails where **you manually replied** to a received email.

**Includes:**
- Responses you typed and sent
- Replies to specific received emails
- Your personal compositions

**Badge:** Green "↩️ Reply to Email #X" badge shows the original email ID

**How it works:**
- When you open an email and click "Reply"
- Compose a message and send
- System tracks it as a reply with `in_reply_to` reference

### 4. 📤 Outbox
Shows **pending emails not yet sent**.

**Status:** Yellow "⏳ Pending" badge

**Why emails might be pending:**
- Recently queued for sending
- Waiting for server availability
- Scheduled for later sending
- Network issues preventing send

**What to do:**
- Check email configuration
- Verify recipient addresses
- Retry sending via UI (if option available)

### 5. ❌ Failed
Shows emails that **failed to send**.

**Status:** Red "✗ Failed" badge

**Includes error details:**
- Error message describing what went wrong
- Recipient address that failed
- Time of failure attempt

**Common failures:**
- Invalid email address
- SMTP server unreachable
- Authentication failed
- Recipient rejected message

**What to do:**
- Fix the error (check recipient address)
- Retry sending
- Check email configuration in Settings

## Email Details in Each View

For every email, you'll see:

### Basic Info
```
To: recipient@example.com
Subject: Email subject line
Body Preview: First 3 lines of the email content
```

### Status Badges
- ✓ Sent (green) - Successfully delivered
- ✗ Failed (red) - Failed to send
- ⏳ Pending (yellow) - Waiting to send

### Type Indicators
- 🤖 AI Generated - Auto-replied by AI
- ↩️ Reply to Email #X - Manual reply to received email
- 📝 From Draft #X - Sent from a saved draft

### Metadata
- **Sent timestamp** - When the email was sent
- **Recipients** - To, CC, BCC addresses if used
- **Error message** - If sending failed, shows why

### Body Preview
- Shows first 3 lines of email body
- Click to expand or view full content (future feature)

## Database Schema

Behind the scenes, emails are stored in the `sent_emails` table with:

```sql
CREATE TABLE sent_emails (
    id INTEGER PRIMARY KEY,
    to_address VARCHAR(255),      -- Recipient
    cc_address VARCHAR(500),      -- CC recipients (comma-separated)
    bcc_address VARCHAR(500),     -- BCC recipients (comma-separated)
    subject TEXT,                 -- Email subject
    body TEXT,                    -- Plain text body
    html_body TEXT,               -- HTML version
    ai_generated BOOLEAN,         -- TRUE if auto-generated by AI
    in_reply_to INTEGER,          -- ID of replied-to email (NULL if original)
    from_draft INTEGER,           -- ID of draft used (NULL if new)
    status VARCHAR(50),           -- 'sent', 'failed', 'pending'
    error_message TEXT,           -- Error details if failed
    sent_at DATETIME,             -- When sent
    created_at DATETIME,          -- When record created
    updated_at DATETIME           -- Last update
);
```

## API Endpoints

### Get Sent Emails
```bash
GET /api/email/storage/sent
  ?page=1
  &per_page=20
  &ai_only=false
  &sort_by=date
  &sort_order=desc
```

## Tips & Tricks

### Finding Specific Emails

1. **Find AI responses:**
   - Click "🤖 AI Auto-Replies" filter
   - Shows only AI-generated emails

2. **Find your manual replies:**
   - Click "↩️ Manual Replies" filter
   - Shows emails you personally sent in response

3. **Find what's not yet sent:**
   - Click "📤 Outbox" filter
   - Check status of pending emails

4. **Find problems:**
   - Click "❌ Failed" filter
   - See what went wrong and why

5. **Find from drafts:**
   - Look for "📝 From Draft #X" badge
   - Connects sent email to original draft

### Quick Checks

**How many emails has AI sent?**
- Look at "🤖 AI Auto-Replies (X)" count

**How many failed emails are there?**
- Look at "❌ Failed (X)" count

**Do I have unsent emails?**
- Check "📤 Outbox (X)" - should be 0 normally

## Troubleshooting

### No Sent Emails Appearing
1. Check if you've sent any emails yet
2. Refresh the page
3. Check backend logs for errors
4. Verify database is working

### AI Auto-Replies Not Showing
1. Verify auto-reply is enabled in Email settings
2. Check if emails are actually being received
3. Look for errors in backend logs
4. Verify LLM configuration

### Failed Emails Stack Up
1. Fix the underlying issue (usually email config)
2. Go to Settings → Email and reconfigure
3. Test connection to verify it works
4. Retry sending failed emails

### Pagination Shows 0 Pages
1. Refresh the page
2. Try reloading sent emails
3. Check database connection
4. Check backend logs for SQL errors
